# NeuroFly v0.5.1rc2 graphics candidate (PRERELEASE)

1. Initial packaging preparation on 8 October 2026 used accepted presentation source `8d9d7937c4780b8aa90c243460730fb354500feb` and changed version labels, release documentation and optional-archive instructions. The final candidate also fixes installed-gallery loading when HEAD is unsupported and recovers exact request acknowledgements after an HTTP timeout. Recovery accepts only a final receipt for the same request, action and daemon; missing, stale or unrelated evidence remains unknown. The two-second request timeout is unchanged and mutations are never resent. The tag `v0.5.1rc2` and the GitHub pre-release were made on 8 October 2026; historical 0.5.1rc1 notes remain unchanged. Root owns final installed-browser qualification; command acknowledgements alone do not establish an HTTP timing or browser pass.
2. The candidate includes renderer `4f10ccd`, repaired environment v4 source and scene source (their pre-rewrite commits are not in the published master history). The separate BODY-MAP candidate is excluded; the documented conditional FlyGym66→18 telemetry limitation remains.
3. Without `?assets=hq`, the dashboard retains its procedural fly. With the flag, HQ female appearance is the default; Female/Male controls select presentation only, independent of brain sex, dataset, physiology and behaviour. Missing variants retain the neutral/procedural fallback. Embodied replay retains its neutral HQ surface and recorded position-based pose.
4. The 3D view includes camera presets, theme and frame-time quality controls. Appearance selection retains active3D and those settings. The gallery suppresses embedded GLB lights during review, extends its review floor from clip trajectories and labels composite-scene handedness N/A; individual environment animals use anatomical left +X without reflection.
5. Gallery clips are **ILLUSTRATIVE, not simulated behaviour**. Environment v4 clips are the repaired candidate; failed v3 and older fly sets remain explicitly labelled negative evidence. Mantis walking uses cross-species proxies and artistic estimates: no suitable mantis walking dataset was identified in the bounded source review. Predator decoration supplies no predator behaviour or retinal input.
6. The environment inspector separates scalar field, delivered receptor input and neural response. Engine odours are static normalised fields with no chemical identity, transport or wind advection. Wind-vane DEMO motion is a preview; explicit zero wind is CALM, while missing/nonfinite wind remains NOT SIMULATED. Presentation and delivery do not establish sensing, biological success or real-time performance.
7. Install `neurofly-0.5.1rc2-py3-none-any.whl` in a fresh environment. HQ files are optional and separate: extract `neurofly-hq-assets-0.5.1rc2.zip` into the installed package's `web/assets/hq` directory, or the matching checkout path; verify `SHA256SUMS`. The archive uses the existing explicit whitelist, with provenance/contracts and labelled historical negatives; no recordings, editable .blend files or staging extras are included.
8. Prior Root browser acceptance covered the read-only frontend proxy at the accepted source. It was **not** a fresh installed-daemon runtime/browser qualification. Clean installation, source identities and file resolution are packaging checks; installed simulation, split-process startup, live controls, clocks, owner synchronization and browser errors still require a separate gate. Existing graph-I/O migration and scientific limitations from 0.5.1rc1 remain applicable.
