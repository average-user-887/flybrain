This page is retired

The single-file “Scientific Instrument” bundle that used to live here was an unmaintained copy of the dashboard. It lacked the dashboard's graph-identity and backend checks, and its bundler was never part of the repository. It is no longer supported and nothing here runs.

Use the canonical dashboard instead: start the daemon with neurofly run --host 127.0.0.1 --port 8769, then open http://localhost:8769. In a checkout, the page itself is web/index.html.

The old page is kept in git history. Its last commit and the reason it was retired are listed in docs/RETIREMENT_INDEX.md.
